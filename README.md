# Calendrier franco-chinois

**👉 https://lcarwy.github.io/calendrier-cn-fr/**

Un calendrier qui affiche dans une même vue :

- les jours fériés français (métropole, Alsace-Moselle) ;
- les jours fériés chinois, avec les **jours de rattrapage** travaillés (调休) ;
- le calendrier lunaire, les 24 termes solaires et les fêtes traditionnelles chinoises ;
- vos propres événements.

Vos données restent **dans votre navigateur** : pas de compte, pas de serveur. L'application fonctionne hors ligne et peut être ajoutée à l'écran d'accueil de votre téléphone.

## Installer sur votre téléphone ou ordinateur

- **iPhone / iPad** (avec Safari) : bouton Partager, puis « Sur l'écran d'accueil ».
- **Android** (Chrome) : bouton « Installer » en haut de la page, ou menu ⋮ → « Installer l'application ».
- **Ordinateur** (Chrome, Edge) : bouton « Installer » en haut de la page, ou icône d'installation dans la barre d'adresse.

Vos événements ne sont pas synchronisés entre appareils : utilisez **Réglages → Sauvegarde** pour les exporter et les importer.

## Sources des données

- Jours fériés chinois : avis annuels du Conseil des affaires de l'État ([gov.cn](https://www.gov.cn)), via [NateScarlet/holiday-cn](https://github.com/NateScarlet/holiday-cn) (MIT)
- Calendrier lunaire et termes solaires : [tyme4ts](https://github.com/6tail/tyme4ts) (MIT)
- Jours fériés français : calculés selon le Code du travail, vérifiés avec le [jeu de données officiel](https://www.data.gouv.fr/dataservices/672cf9c286ab0cda58d92dc4) (Licence Ouverte)
